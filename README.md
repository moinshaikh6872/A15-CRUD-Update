# A15-CRUD-Update
CRUD page 2 - Update (PUT from the page
Add the ability to edit an existing record from the page and send the change to the API.

## Instructions
1. Install dependencies: `pip install -r requirements.txt`
2. Run the FastAPI backend: `uvicorn main:app --reload`
3. Open `index.html` in your web browser to test adding and updating records via `POST` and `PUT` methods.
